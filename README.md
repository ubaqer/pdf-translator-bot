# بوت ترجمة ملفات PDF وPPTX

يستخدم البوت Gemini للترجمة واستخراج النصوص من ملفات PDF المصوّرة والصور والشرائح.

## التشغيل

1. ثبّت المتطلبات:

   ```powershell
   pip install -r requirements.txt
   ```

2. أنشئ ملف `.env` بجانب `bot.py`، وضع الإعدادات التالية:

   ```dotenv
   TELEGRAM_BOT_TOKEN=رمز_بوت_تيليجرام
   GEMINI_API_KEY=مفتاح_Gemini
   BOT_OWNER_ID=
   TELEGRAM_PROXY=
   MAX_PDF_PAGES=120
   ```

3. شغّل البوت:

   ```powershell
   python bot.py
   ```

في Windows يمكن تشغيل `run.bat` بعد إعداد ملف `.env`.

## أوضاع الترجمة

- الترجمة الشفافة فوق الأصل مع توسيع المسافات وترحيل المحتوى عند امتلاء الصفحة.
- الترجمة الثنائية مع الحفاظ على تصميم الصفحة.
- الترجمة النصية إلى ملفات PDF وWord.
- OCR للملفات المصوّرة والصور، وترجمة الشرائح.

`GEMINI_API_KEY` مطلوب لجميع أوضاع الترجمة. لا يحتاج البوت إلى إعداد LibreTranslate أو Google Translate API.

## مواد المذاكرة

بعد الترجمة، يمكن إنشاء اختبار إنكليزي بعدد ومستوى قابلين للاختيار، مع مفتاح إجابات في ملف منفصل أو مضمّن في نهاية الاختبار. كما يمكن إنشاء خريطة ذهنية مرئية بصيغة PNG، وملخص، وقاموس مصطلحات إنكليزي-عربي. يمكن حصر هذه المواد بصفحات أو شرائح محددة، أو بفصل ظاهر في النص مثل `Chapter 2`.
